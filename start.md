# Cómo arrancar

## 1. Backend (Python)

```bash
cd backend
python -m uvicorn main:app --port 8001 --reload
```

Queda escuchando en http://localhost:8000

## 2. Frontend (React — primera vez)

```bash
cd frontend
npm install       # solo la primera vez
npm run dev
```

Abre el navegador en http://localhost:5173
